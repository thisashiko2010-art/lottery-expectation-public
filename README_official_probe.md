# Official Lottery Source Probe v0.6

## Purpose

This tool checks access to the six official Mizuho Bank lottery result pages.

It is an isolated diagnostic tool. It does not modify the existing third-party data collector.

## Supported games

- Mini Loto
- Loto 6
- Loto 7
- Numbers 3
- Numbers 4
- Bingo 5
